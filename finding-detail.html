Critical Hardcoded API key

Description

A service key is written directly into the source code. Because the repository is public, anyone who can read the code can read this key. The key also remains in past commits, so deleting it from the file is not enough on its own.

Affected code

src/config/api.js — line 42

40  const client = axios.create({
41    baseURL: process.env.API_URL,
42    apiKey: "sk_live_4eF9... (redacted)",
43  });

Suggested fix

  1. Revoke the key immediately and generate a new one — a leaked key is no longer safe.
  2. Move the new key into an environment variable and add that file to .gitignore.
  3. Purge the old key from the commit history; removing it from the file is not enough.
